1. Operações CRUD no PostgreSQL

CRUD é a sigla para as 4 operações básicas sobre dado: Create (INSERT), Read (SELECT), Update (UPDATE) e Delete (DELETE).

ComandoO que faz
INSERT INTO tabela (...) VALUES (...)Adiciona uma nova linha
UPDATE tabela SET col = valor WHERE ...Altera linhas que já existem
DELETE FROM tabela WHERE ...Remove linhas
⚠️ Sem WHERE, UPDATE e DELETE afetam TODAS as linhas da tabela — sem exceção, sem confirmação. Sempre confira o WHERE antes de rodar. 
-- adiciona um pedido novo
INSERT INTO pedidos (cliente, filial, item, valor, data_hora)
VALUES ('Beatriz Ramos', 'Centro', 'Suco Natural', 9.50, NOW());

2. Funções de Número, Texto e Data

CategoriaFunçãoO que faz
NúmeroROUND(valor, casas)Arredonda com N casas decimais
TextoUPPER(texto) / LOWER(texto)Deixa maiúsculo / minúsculo
TextoCONCAT(a, b, ...)Junta textos
DataEXTRACT(MONTH FROM data)Extrai uma parte da data
-- nome em maiúsculas, valor arredondado
SELECT UPPER(cliente) AS cliente_maiusculo, ROUND(valor, 0) AS valor_arredondado
FROM pedidos;

3. Subqueries

Uma subconsulta é uma consulta escrita DENTRO de outra. Ela roda primeiro, produz uma lista de valores, e essa lista vira filtro da consulta principal.

-- pedidos de itens da categoria Prato Principal
SELECT cliente, item, valor
FROM pedidos
WHERE item IN (
    SELECT item FROM produtos WHERE categoria = 'Prato Principal'
);

4. Uma Primeira Olhada: Variáveis, Functions e Transactions

Esta seção é introdutória — o objetivo é reconhecer esses recursos, não dominá-los ainda.

RecursoO que é
Bloco anônimo (DO $$ ... $$)Roda lógica com variável, sem salvar como função
FunctionBloco de lógica reutilizável, chamado dentro de um SELECT
TransactionAgrupa vários comandos: ou todos aplicam (COMMIT), ou nenhum (ROLLBACK)
-- function que aplica desconto
CREATE OR REPLACE FUNCTION valor_com_desconto(preco NUMERIC, pct NUMERIC)
RETURNS NUMERIC AS $$
BEGIN
    RETURN preco - (preco * pct / 100);
END;
$$ LANGUAGE plpgsql;
