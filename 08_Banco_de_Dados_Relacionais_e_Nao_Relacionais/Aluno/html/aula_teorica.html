1. Fundamentos de Business Intelligence e Modelagem de Dados

Um banco de dados é um programa que fica sempre ligado, rodando em segundo plano, guardando o dado de forma organizada e permitindo que várias pessoas leiam e alterem essa informação ao mesmo tempo — diferente de um arquivo CSV, que você abre, lê e fecha.

Business Intelligence (BI) é o processo de transformar dado bruto em informação que ajuda alguém a decidir algo, seguindo etapas parecidas com o que você já faz desde a Semana 06:

🛠 Na prática (Python/SQL): uma consulta estilo OLTP busca 1 registro específico — pedidos[pedidos["id_pedido"] == 3]. Uma consulta estilo OLAP resume muitos registros — pedidos.groupby("filial")["valor"].sum(). O notebook desta semana pratica os dois com o mesmo arquivo pedidos_sabor_caseiro.csv.

2. PostgreSQL e pgAdmin — Instalação, Configuração e Primeira Conexão

O PostgreSQL é um programa completo, separado do Python, que fica rodando sozinho em segundo plano (um servidor) esperando alguém se conectar. Diferente de uma biblioteca (%pip install), ele precisa ser instalado como um programa de verdade na sua máquina.

TermoO que é
PostgreSQLO SGBD — o programa que guarda e organiza os dados de verdade
pgAdminPrograma com tela e botões pra ver e mexer no PostgreSQL
psycopg2Biblioteca Python que conecta seu código ao PostgreSQL
SQLA linguagem usada para pedir e alterar dado num banco relacional
⚠️ Confusão comum: o PostgreSQL vem com um usuário chamado postgres e, separadamente, um banco de dados que também se chama postgres — são 2 coisas diferentes. Você cria um banco novo, sabor_caseiro, para este curso.

3. Queries Básicas no PostgreSQL

Toda consulta de leitura em SQL começa com SELECT (o que eu quero ver) e FROM (de onde vem).

ComandoO que faz
SELECT * FROM tabelaTraz TODAS as colunas
SELECT col1, col2 FROM tabelaTraz só as colunas escolhidas
SELECT col AS apelidoRenomeia a coluna no resultado
SELECT DISTINCT colRemove valores repetidos
... LIMIT NTraz só as N primeiras linhas
... ORDER BY colOrdena o resultado (ASC/DESC)
-- 5 pedidos mais recentes, só com as colunas que interessam
SELECT id_pedido, cliente AS nome_cliente, valor
FROM pedidos
LIMIT 5;

4. Filtros no PostgreSQL

O comando WHERE filtra as linhas de uma consulta, mantendo só as que atendem a uma condição.

Operador/ComandoO que faz
=, <>, >, <, >=, <=Comparação
AND / OR / NOTCombina condições
LIKE '%texto%'Busca um texto dentro de outro
IN (...)O valor está numa lista?
BETWEEN a AND bO valor está num intervalo?
IS NULL / IS NOT NULLO valor está vazio (ou não)?
⚠️ O PostgreSQL é case-sensitive: WHERE filial = 'centro' (minúsculo) NÃO encontra as linhas gravadas como 'Centro' (maiúsculo). 
-- pedidos da filial Centro, acima de R$ 30
SELECT cliente, filial, item, valor
FROM pedidos
WHERE filial = 'Centro' AND valor > 30
ORDER BY valor DESC;

5. Funções de Agregação e Agrupamentos

Funções de agregação calculam um valor a partir de várias linhas.

FunçãoO que faz
COUNT(*)Conta quantas linhas existem
SUM(coluna)Soma os valores da coluna
AVG(coluna)Calcula a média
MAX(coluna) / MIN(coluna)O maior e o menor valor

Sozinha, uma função de agregação resume a tabela INTEIRA. Para resumir por grupo (por filial, por item...), existe o GROUP BY: ele separa as linhas em grupos antes de calcular.

-- faturamento e quantidade de pedidos por filial
SELECT filial,
       COUNT(*) AS qtd_pedidos,
       SUM(valor) AS faturamento
FROM pedidos
GROUP BY filial
ORDER BY faturamento DESC;
